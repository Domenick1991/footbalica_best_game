# Footbolica best game

Откройте [index.html](index.html) в браузере. Сборка, сервер и установка зависимостей не нужны. Для игры на телефоне используйте горизонтальное положение экрана.

Поле, игроки, мяч и ворота отображаются в WebGL через локальную копию Three.js 0.149.0. Если браузер не поддерживает WebGL, игра автоматически показывает прежнюю 2D графику. Лицензия Three.js находится в [vendor/THREE-LICENSE.txt](vendor/THREE-LICENSE.txt).

Для щита ТФЛ в WebGL используется встроенная копия [assets/tfl.png](assets/tfl.png) в `assets/tfl-data.js`, чтобы текстура загружалась и при открытии игры через `file://`. При замене логотипа нужно обновить обе копии.

Значок KFC на форме Аркундия Сандерса хранится в [assets/sunders.png](assets/sunders.png) и продублирован в `assets/sunders-data.js` для запуска через `file://`. При замене изображения нужно обновить обе копии.

Рисунок купюр для формы Коляна хранится в [assets/dollar.png](assets/dollar.png) и продублирован в `assets/dollar-data.js` для запуска через `file://`. При замене изображения нужно обновить обе копии.

Машина Мишани хранится в [assets/car.png](assets/car.png) и продублирована в `assets/car-data.js`. В игре её фон скрывается контурной маской из `assets/car-outline.js`, чтобы машину было видно за решёткой и при запуске через `file://`.

Выберите футболиста, укажите направление на поле (на телефоне ведите пальцем по экрану вне нижней панели), настройте закрутку, затем удерживайте и отпустите кнопку удара для выбора силы. Жёлтая дуга показывает ожидаемый полёт; реальный удар может отклониться. Гол прибавляет очко, любой промах отнимает очко. Серия заканчивается при нуле.

Сидорьньё бьёт левой ногой, остальные игроки — правой. Озонмен всегда забивает при максимальной силе удара. Косогорчик каждый третий удар промахивается по мячу и теряет очко.

Пенальти и три вида штрафных выпадают с вероятностью 25% каждый. Точка центрального штрафного смещается в пределах 2 м от центра ворот; точки фланговых ударов случайно выбираются от 2 до 4 м влево или вправо. Рекорд и настройка звука хранятся только в браузере через `localStorage`.

Проверка игровой логики:

```sh
node --test logic.test.cjs
```
