# Footbolica best game

Откройте [index.html](index.html) в браузере. Сборка, сервер и установка зависимостей не нужны. Для игры на телефоне используйте горизонтальное положение экрана.

Поле, игроки, мяч и ворота отображаются в WebGL через локальную копию Three.js 0.149.0. Если браузер не поддерживает WebGL, игра автоматически показывает прежнюю 2D графику. Лицензия Three.js находится в [vendor/THREE-LICENSE.txt](vendor/THREE-LICENSE.txt).

Для щита ТФЛ в WebGL используется встроенная копия [assets/tfl.png](assets/tfl.png) в `assets/tfl-data.js`, чтобы текстура загружалась и при открытии игры через `file://`. При замене логотипа нужно обновить обе копии.

Выберите футболиста, укажите направление на поле, настройте закрутку, затем удерживайте и отпустите кнопку удара для выбора силы. Жёлтая дуга показывает ожидаемый полёт; реальный удар может отклониться. Гол прибавляет очко, любой промах отнимает очко. Серия заканчивается при нуле.

Пенальти выпадает с вероятностью 20% для каждого удара. Штрафные выполняются со случайных позиций. Рекорд и настройка звука хранятся только в браузере через `localStorage`.

Проверка игровой логики:

```sh
node --test logic.test.cjs
```
